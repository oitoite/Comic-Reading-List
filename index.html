    Find on Marvel

    Links

    Some services address individual issues by id rather than by name — a search template cannot produce those, so paste them here. Open the issue on the service, copy the address bar (e.g. https://www.marvel.com/comics/issue/25182/fantastic-four-1998-570) and drop it on the matching row. A blank row falls back to the entry’s direct link, then to the service search. Links must start with http:// or https://.

    Services

    When neither the issue nor the entry has a direct link, Longbox builds one from these templates. {q} becomes the series and issue together (Fantastic Four #570); {series} and {issue} are available separately, for a search that returns nothing when an issue number is in the query. The DC template is still a placeholder — run a search on the service, copy the address bar of the results page, and swap the search term for {q}. Templates must start with http:// or https://.

    Get a free key at developer.marvel.com, then add this site to your authorized referrers so Marvel accepts calls from the browser. Only the public key belongs here — never the private one: this page is static, so anything it stores is readable by anyone using this browser.
